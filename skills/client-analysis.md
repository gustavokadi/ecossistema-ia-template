# Skill — client-analysis

## Função
Análise completa do cliente antes de qualquer entregável.
SEMPRE rodar antes de qualquer outro agente com um cliente novo.

## Inputs
- URL do site do cliente
- @ do Instagram do cliente
- 2–3 concorrentes (URL ou @Instagram)
- Segmento/nicho do cliente

## Output completo

### 1. ICP (Cliente Ideal)
- Perfil demográfico (idade, cargo, localização)
- Situação atual (o que está vivendo)
- Dor principal (o que o impede de crescer)
- Desejo (o que quer alcançar)
- Linguagem que usa (como descreve os problemas)
- Onde está online (canal preferido)
- Como toma decisão de compra

### 2. Posicionamento
- Como o cliente se apresenta hoje
- Como deveria se posicionar
- Gap entre atual e ideal
- Palavra que deve ownar no mercado

### 3. Tom de voz
- Tom atual (análise do Instagram e site)
- Tom recomendado
- Exemplos de como deveria escrever

### 4. Diferenciais
- O que separa do concorrente
- O que os concorrentes fazem bem (e o cliente não)
- Oportunidade não explorada

### 5. Gaps de conteúdo
- Temas que os concorrentes cobrem e o cliente não
- Formatos que funcionam no nicho e o cliente não usa
- Frequência ideal vs. atual

### 6. Recomendações estratégicas
- 3 ações prioritárias imediatas
- Canal para atacar primeiro
- Tipo de conteúdo para começar
- Quick win (resultado rápido possível)

## Onde salvar
Preencher `_memoria/` com base nessa análise:
- `empresa.md` → dados do cliente
- `persona.md` → ICP gerado
- `estrategia.md` → recomendações
- `preferencias.md` → tom de voz e estilo
