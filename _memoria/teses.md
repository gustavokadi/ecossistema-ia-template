# Memória — Teses

> Preenchido na implantação a partir do bloco "O que você defende" da entrevista (a discordância
> que o cliente já tem e a frase de confiança que ele diria sem pensar). São de 3 a 5 frases
> curtas que a marca defende. **Nenhuma pauta de conteúdo nasce sem consultar este arquivo
> primeiro.**

## Como usar
- Cada peça de conteúdo relevante defende UMA tese deste banco, mesmo quando a tese não aparece
  literalmente no texto — ela é a espinha, não a frase de abertura
- Tese não é tema, é convicção. "Marketing é importante" não é tese. "Ferramenta não substitui
  processo" é tese
- Teste antes de aceitar uma frase como tese: **alguém do mercado do cliente poderia discordar
  dela?** Se ninguém discordaria, é slogan, não colar aqui
- Numa semana de conteúdo, uma tese domina a maioria das peças (repetição estratégica), no
  máximo uma peça por semana pode existir sem tese nenhuma
