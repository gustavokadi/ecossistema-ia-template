# Memória — Banco de experiências

> Preenchido na implantação a partir do dossiê da entrevista e alimentado toda semana.
> Este é o arquivo que separa conteúdo de verdade de conteúdo de IA. Nenhuma peça deve ser
> produzida a partir de hipótese quando existe experiência real disponível aqui.

## Como usar
- Toda peça de conteúdo deve puxar UMA experiência deste banco como base
- Experiência já usada fica marcada com a data e a peça, pra não repetir em sequência
- Quando o banco tiver menos de 5 experiências não usadas, avisar o cliente e pedir mais
